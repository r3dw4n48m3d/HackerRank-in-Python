# HackerRank Problem
## Problem Title : Lists
### Problem Link : https://www.hackerrank.com/challenges/python-lists/problem?isFullScreen=true

```python
if __name__ == '__main__':
    N = int(input())
    lists = []

    for _ in range(0,N):
        user_input = input()


        if "insert" in user_input:
            lists.insert(int(user_input.split(" ")[1]), int(user_input.split(" ")[2]))
        elif "print" in user_input:
            print(lists)
        elif "remove" in user_input:
            lists.remove(int(user_input.split(" ")[1]))
        elif "append" in user_input:
            lists.append(int(user_input.split(" ")[1]))
        elif "sort" in user_input:
            lists.sort()
        elif "pop" in user_input:
            lists.pop()
        elif "reverse" in user_input:
            lists.reverse()

```
