# HackerRank Problem
## Problem Title : List Comprehensions
### Problem Link : https://www.hackerrank.com/challenges/list-comprehensions/problem?isFullScreen=true


```python
if __name__ == '__main__':
    x = int(input()) # [0,1]
    y = int(input()) # [0,1]
    z = int(input()) # [0,1]
    n = int(input())


result = [[i,j,k] for i in range(0,x+1) for j in range(0,y+1) for k in range(0, z+1) if i+j+k !=n]

print(result)

```
