# HackerRank Problem
## Problem Title : Write a function
### Problem Link : https://www.hackerrank.com/challenges/write-a-function/problem?isFullScreen=true


```python
def is_leap(year):
    leap = False
    
    if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
        leap = True
        
    return leap

year = int(input())
print(is_leap(year))

```
