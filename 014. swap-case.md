# HackerRank Problem
## Problem Title : sWAP cASE
### https://www.hackerrank.com/challenges/swap-case/problem?isFullScreen=true


```python
def swap_case(s):
    lists = list(s)
    for item in range(len(lists)):
        if lists[item] == lists[item].upper():
            lists[item] = lists[item].lower()
        else:
            lists[item] = lists[item].upper()
    lists = "".join(lists)
    return lists

if __name__ == '__main__':
    s = input()
    result = swap_case(s)
    print(result)
```
