# HackerRank Problem
## Problem Title : Finding the percentage
### Problem Link : https://www.hackerrank.com/challenges/finding-the-percentage/problem?isFullScreen=true


```python
def average_marks(marks):
    sum = 0
    for mark in marks:
        sum = sum + mark

    result = sum / len(marks)

    print(f"{result:.2f}")


if __name__ == '__main__':
    n = int(input())
    student_marks = {}
    for _ in range(n):
        name, *line = input().split()
        scores = list(map(float, line))
        student_marks[name] = scores
    query_name = input()

    average_marks(student_marks[query_name])
```
